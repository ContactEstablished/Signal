## Launch commands

From the repository root in PowerShell:

```powershell
pnpm install --frozen-lockfile
. ./scripts/dev-env.ps1
pnpm check
pnpm test
pnpm tauri dev
```

For the isolated September 2025 fixture, close the ordinary instance first:

```powershell
. ./scripts/dev-env.ps1
pnpm dev:seed
```

The expanded invocation verified on pnpm 10.33.2 is:

```powershell
pnpm tauri dev -- -- -- --seed
```

pnpm consumes one separator; Tauri then needs a separator for runner arguments and another for application arguments. The native log must end with `Running target\debug\signal.exe --seed`. `pnpm tauri dev -- --seed` is **not** the seed command: pnpm strips its separator and Tauri rejects the flag. Release binaries reject `--seed`.

`pnpm dev` is only the frontend server. Browser-only access deliberately shows a native-database launch message, not an in-memory substitute. `pnpm build` produces frontend assets. Windows installer distribution is outside M0.

## Implemented boundary

52px header, wordmark, Today badge, Your Day, project dots and underlines, Add project preview, 220px search/palette preview, Settings navigation, and persisted close-to-tray switch. The native titlebar supplies window controls. Header timer status is absent because M0 has no running timers.

The complete handoff token inventory lives in `src/styles/tokens.css`, including later-screen dimensions, tints, borders, type weights/scales, geometry, opacity, focus, shadows, and transitions. Local fonts in `public/fonts/` are Latin WOFF2 subsets from Fontsource 5.3.0's Google Fonts distribution; SIL OFL notices are under `public/fonts/licenses/`. No runtime Google Fonts requests. Sora hour weight is explicitly 600.

Database startup loads the selected SQL-plugin migration, seeds only when authorized by native debug `--seed`, queries real projects/counters, and reports loading/errors with Retry. The seed transaction rolls back on failure and commits its version marker with its records. Subsequent calls with the marker do not overwrite records or settings. Unknown/nonempty unmarked fixtures are refused.

The window store contains only `geometry: {x,y,width,height,maximized}`. Size is logical client size; outer position uses physical screen coordinates. Minimized/transient small sizes are ignored. Move/resize saves debounce for 200ms because Windows emits transient normal-state events during maximize/restore; maximized saves retain the previous normal bounds. Saved positions whose titlebar is outside available monitors are recentered. Tray hiding is allowed only if the native tray exists and hiding succeeds.
